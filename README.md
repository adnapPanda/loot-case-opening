# Loot case opening plugin

Do you ever feel like opening loot chests doesn't have enough suspense? Do you want to experience the thrill of seeing a wheel spin and not knowing what item it will land on?

Now you can!
This plugin adds a wheel spin animation to a few pieces of content so you don't get bored after hours of not getting any items.
